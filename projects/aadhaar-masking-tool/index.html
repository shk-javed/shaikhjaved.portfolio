01 / The problem

Share the document, not the number.

Aadhaar copies get shared all the time, and every copy carries the full 12-digit number. This tool takes an image or PDF, finds the Aadhaar number with OCR, and masks the first eight digits so only the last four stay visible, the same idea as a masked Aadhaar.

It is a privacy-preserving OCR app: detection and masking happen in one Django web flow, and the masked file comes back as a download.

03 / Features

What the app does.

Source: README, checked against the code

  • Automatic detection

    Finds the Aadhaar number with OCR: PaddleOCR first, Tesseract if PaddleOCR finds nothing.

  • Images and PDFs

    Accepts JPG, PNG and PDF; every page of a PDF is masked and rebuilt.

  • Masks 8, keeps 4

    Covers the first eight digits and writes “XXXX XXXX” over them; the last four stay as they were.

  • Rotated text

    PaddleOCR runs with its text-angle classifier on, so rotated text can still be read.

  • Skips look-alikes

    Numbers sitting next to words like VID, mobile, phone or email are ignored.

  • Simple web UI

    A Django page to upload a file, preview the result and download the masked output.

04 / As implemented

What the code actually does.

Source: The code (masking/utils/ocr_utils.py, masking/views.py)
  1. 01

    Accept the file

    views.py takes .jpg, .jpeg, .png or .pdf. PDFs are opened with PyMuPDF and every page is rendered at 2×; images are decoded with OpenCV.

  2. 02

    Prepare the image

    enhance_for_ocr boosts contrast with CLAHE (clip limit 2.0, 8×8 tiles); a blurred greyscale copy is kept for Tesseract.

  3. 03

    OCR, with a fallback

    PaddleOCR runs with its angle classifier on. Tesseract (English) runs only if PaddleOCR returns nothing or fails.

  4. 04

    Pick the number

    First any token with exactly 12 digits, then three 4-digit tokens on one line; only if neither matches, the first token with 11–13 digits.

  5. 05

    Skip look-alikes

    is_near_disqualifier drops candidates within three text items of words such as virtual, VID, mobile, phone, email or contact (also in Hindi).

  6. 06

    Mask

    The left 8/12 of the number’s box is filled with the box’s median colour (blur or pixelate are options), then “XXXX XXXX” is drawn on top.

  7. 07

    Return it

    The result is saved as masked_<name>.png or a rebuilt image-only PDF, with a preview of page 1, and offered for download.

Read from the source code, not run. The code defines a few regex patterns that the current version doesn’t use; detection relies on the digit-length checks above.

07 / Why no live demo

Honest about the demo.

The real app needs a Python server with the OCR models installed (its requirements include PaddlePaddle and PyTorch), which a static portfolio can't run.

And a public upload box would invite people to send real Aadhaar cards. So this page shows a simulation that runs in your browser with a made-up number, and the full code is on GitHub.
